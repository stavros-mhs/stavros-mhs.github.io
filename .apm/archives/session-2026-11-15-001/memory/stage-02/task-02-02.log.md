# Task 2.2 - Apply the accent roles

## Summary
The accent is now used in the places the Task asked for, and the theme toggle can be reached and focused with the keyboard. During the review the User asked for several changes the Plan did not cover: a cream light palette, softer links, lighter heading weights, section headings in the accent, and a toggle whose icon and knob show the mode you will switch to. The User reviewed the result on localhost in both themes and approved it. The outcome is Success, because the objective is met and the User accepted the result. Several decisions differ from the Spec and Plan, and they are listed under Important Findings for the Manager to record.

## Output
- `style.css`, on `feat/palette-roles`. Commits from `e0ed63b` (the original Task work) to `570208a` (the last change), nine in total. The diff against `main` is one file, 50 insertions and 45 deletions.
- The Task's own changes: headings use `--text` at first, then the accent by User request; `.contact-list svg` uses `--text-muted`; the h1 stays on `--accent`; the toggle is visually hidden instead of `display: none`, and its label has a focus ring.
- The User's review changes, on the same branch: the light palette, link colours, heading and bold weights, section heading colour, and the toggle knob and icon behaviour.
- No change to `index.html`, `trial-fonts.html` or the font.

## Validation
- Contrast script (run by the Worker): final run, 16 of 16 pairs PASS, 8 per theme. The eighth pair in each theme is the focus ring against the navbar, at 3:1 or higher as WCAG 1.4.11 requires.
- Keyboard check (run by the Worker, headless Chromium, `focus_check.mjs`): 8 of 8 PASS. Tab reaches the toggle after the four nav links, the toggle is not `display: none`, and the focus ring is a solid outline in both themes. No console or page errors.
- Toggle states (run by the Worker, headless Chromium): in light mode the moon is visible on a dark knob at the left. In dark mode the sun is visible on a cream knob at the right.
- Static checks (run by the Worker): no `dark-mode` or `body:not` hooks, no `;;`, and no removed token names remain in `style.css` or `index.html`.
- User action (run by the User, live browser): reviewed both themes on localhost, with the focus ring, icons, knob, links and headings. Approved.

## Important Findings
- **Section headings use the accent, not the text colour.** The Spec's Rules for use say other headings use `--text`. The User chose the accent for section headings in both themes, because they wanted them to stand apart from the body text. The Spec must be updated.
- **The light palette changed from the Spec's table.** Light mode is now a cream paper palette: background `#f4ecdc`, navbar `#e8dcc6`, text `#5a4c3c`, muted text `#6a5b49`, accent `#b5602e`, link `#805832`, hover `#8a3c12`, rule `#d7c9ad`. The Spec's table must be updated. The dark palette is unchanged.
- **New tokens not in the Spec:** `--focus` (defined per theme, dark `#e8954d`, light `#805832`), and four fixed toggle colours defined once at the top of the file: `--knob-dark` (`#2e2e2e`), `--knob-light` (`#f4ecdc`), `--moon-icon` (`#e8954d`) and `--sun-icon` (`#b5602e`).
- **Heading and bold weight is 500 in both themes,** where it was bold. Only the regular weight of the font is loaded, so the browser's bold was an imitation. The User accepted this in both themes.
- **The toggle now shows the mode you would switch to.** The moon is shown in light mode, on a dark knob, and the sun is shown in dark mode, on a cream knob. The Spec's Theme Behavior section does not cover this.
- **Link contrast is close to the limit.** In light mode, the link `#805832` is 4.61:1 on the navbar, against the 4.5:1 minimum. Lighter links would need a lighter navbar.
- **The h1 and section headings in light mode are 3.82:1 on the background.** The accent is used only on large text and icons, so this meets the 3:1 requirement for large text.
- **The body font is still IBM Plex Sans,** the font the User chose. Task 2.3 deletes `trial-fonts.html`, and it has no font change to make.
