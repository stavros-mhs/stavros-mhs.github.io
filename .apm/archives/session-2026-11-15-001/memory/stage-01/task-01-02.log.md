- **Dark link colour changed, `#c9a87c` to `#d8b78e`.** The old colour is 3.96:1 on the navbar's `--surface` (`#4a4a4a`), which fails the 4.5:1 requirement for the nav links. The new colour passes at 4.68:1.
- **Dark link hover changed to `#f5b06e`, not the Spec's `#f0a862`.** The Spec's value is 4.42:1 on the navbar, which fails. The new value passes at 4.78:1. Hover was `#e8954d` before this Task.
- **Sun and moon toggle icons changed in dark mode, `#c87941` to `#e8954d`.** They now use `--accent`. The light-mode icons are unchanged, because the old light `--orange` and `--orange-accent` were both `#c47030`.
- **Visited and active links changed.** Visited links now use `--link`, and active links use `--link-hover`, as the Task Prompt asks. These are visible changes: dark visited links were `#a88860` and are now `#d8b78e`, and light visited links were `#8f6535` and are now `#7a4c1a`.
- **Light link and hover colours changed, as the Task required.** `#b8874a` was 2.79:1 on the light background and failed. Hover moved from `#d4700f` to `#8f3d0a`.
- **`--text-muted` is defined but not used yet.** No rule uses it in this Task. The contact icons still use `--accent`, which the Spec changes in Task 2.2.
- **The light accent passes only as large text.** `#c47030` is 3.23:1 on the light background. It is used only on the h1 and h2 headings, which count as large text, so it meets the 3:1 threshold used for them. The contact icons also use it, which is a non-text use.
