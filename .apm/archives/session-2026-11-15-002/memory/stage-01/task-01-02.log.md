# Task 1.2 - Add the Animations switch and the saved mode

## Summary
The page now resolves a motion mode before first paint and sets it on `<html>` as `data-motion`. It takes the saved `motion` choice first, then `prefers-reduced-motion: reduce` (which gives `minimal`), and otherwise `animated`. A switch labelled "Animations" sits in the navbar, between the Contact link and the theme toggle. It is a `<button role="switch">` with `aria-checked`, and it starts hidden. A small script shows it and wires the click, which changes `data-motion`, updates `aria-checked`, and saves the choice under `motion`. No motion effect was added. The switch's knob moves at once; the transitions come in Task 2.3. The theme script, the theme toggle and its styles are unchanged. Every Validation check passed.

## Output
- `index.html`: a head script after the theme script that sets `data-motion`; the switch button before the theme toggle; a script after the existing theme script that shows the switch and wires the click.
- `style.css`: the switch styles, including the focus ring and knob position, and a `[hidden]` rule so the switch stays hidden until the script shows it. Mobile rules are inside the existing 600px media query.
- Commit `3c2adcf`, `feat: add the animations switch and saved mode`, on `feat/animations-switch`, with those two files only.
- The working directory is the repository root. Screenshots are in the scratchpad (`t12-shots/`).
