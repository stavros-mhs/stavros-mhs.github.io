## Method
Headless Chromium through Playwright, against the live server on port 8000. Each route loads in animated mode, and the script waits until that route's own page has built and faded in. For every route, theme and width, it counts:
- **Sideways (px):** `scrollWidth` minus the viewport width.
- **Text outside viewport:** text nodes whose rectangles, from `Range.getClientRects`, lie outside the viewport horizontally.
- **Overlapping blocks:** pairs of text-bearing elements, neither containing the other, whose boxes overlap by more than 1px on both axes.
- **Text outside terminal:** text rectangles outside the terminal's own box.
- **Body text:** the smallest computed font size of text inside the terminal and the markdown below it.
- **Burger:** computed `display` and whether its box lies inside the viewport.

The first run counted element boxes instead of text rectangles, so it missed the error line's overflow. I changed the count to text rectangles and re-ran the baseline before any fix. The table below is from the run after the fix.
