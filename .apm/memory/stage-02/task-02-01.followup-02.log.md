## Important Findings
1. **The navbar is not taller, so the terminal did not move.** The Task expected the names' larger size to make the navbar taller, and the terminal's height to change with it. The names' line is 34px high, and the toggle sets the navbar's height at 40px, so the navbar stays 72px tall. The terminal's centre is unchanged, so I did not adjust the terminal's height.
2. **`index.html` was changed, against the Task's Output.** The Output allows `index.html` only if step 4 needs it. But the fade constant `FADE_MS` in the timeline script sets the time between the fade's start and the first command. With the fade at 750 ms and that constant still at 1500 ms, `whoami` would start 1150 ms after the fade ended. The Task's 400 ms wait cannot hold without that one change, so I made it. The rest of the timeline is unchanged.
3. **The spacing between the names is unchanged.** The names are separated by single spaces, as before. At 21.28px the row reads as one line, and it looks in proportion to the terminal text in the screenshot. I did not change the spacing, as the Task asks.
4. **Hover, focus and the colours are unchanged.** The focus ring, the hover colour and the link colours are the same rules as before. Only `font-size` changed in `.nav-container a`.
5. **Sampling tolerance.** The fade's start is measured to the microsecond, but the `whoami` time is taken when its character is written, which can be up to a frame after the timer fires. The two offsets I report (6.3 ms and 15.4 ms) are the measured differences, and both are inside one frame.
6. **Commit trailers.** None, as `AGENTS.md` requires. This follows Task 1.2's Important Finding 6.
